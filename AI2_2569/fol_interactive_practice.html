Part 1 · Guided lesson

How to translate English into FOL

Natural-language sentences describe objects, their properties, and relationships. First-Order Logic makes these precise using predicates, variables, quantifiers and logical connectives.

Object / constantalice, cs221
A named individual or object
Variablex, y
An object that can vary
PredicateStudent(x), Takes(x,y)
A property or relationship
Function (term)MotherOf(x)
Denotes an object, not a truth value

Logical symbols

Five steps for translation

1
Set a domain. Example: people and courses; alternatively, use a one-sorted domain of all objects and distinguish kinds using predicates.
2
Identify nouns and proper names. People like alice become constants; arbitrary people become variables such as x.
3
Identify verbs, adjectives and relations. “is a student” → Student(x); “takes a course” → Takes(x,y).
4
Identify quantity and structure. “Every” typically gives ∀ and a conditional; “some” typically gives ∃ and a conjunction.
5
Check scope and read it back aloud. Quantifier order, negation scope, and direction of the implication can change the meaning.

Worked translations

A · Alice is a student.

Student(alice)

Reason: this sentence states one property of a named object. No quantifier is needed.

B · Every student studies AI.

∀x (Student(x) → Studies(x, ai))

Reason: restrict the universal statement to students using →, not ∧.

C · Some students take CS221.

∃x (Student(x) ∧ Takes(x, cs221))

Reason: one individual must satisfy both predicates, so use ∧.

D · Every student takes some course.

∀x (Student(x) → ∃y (Course(y) ∧ Takes(x,y)))

Reason: the course may differ for each student. Contrast with ∃y (Course(y) ∧ ∀x (Student(x) → Takes(x,y))), which says one common course is taken by all students.

E · No student knows every topic.

¬∃x (Student(x) ∧ ∀y (Topic(y) → Knows(x,y)))

Reason: it denies the existence of a student knowing all topics; it does not say every student knows no topics.

Common errors: translating “Every A is B” as ∀x(A(x) ∧ B(x)); translating “Some A is B” as ∃x(A(x) → B(x)); swapping ∀ and ∃; and forgetting parentheses that control scope.

Part 3 · Inference preparation

Substitution: apply a mapping

A substitution θ maps variables to terms. Applying it to a formula means consistently replacing the specified free variables. In inference, first instantiate the universal rule, then apply its substitution.

θ = {x ↦ alice, y ↦ cs221}
θ(Takes(x,y)) = Takes(alice,cs221)

Function terms may appear: θ(Knows(x, F(x))) = Knows(alice,F(alice)).

Part 4 · Matching expressions

Unification: find the matching substitution

Unlike substitution, unification computes a substitution θ (if one exists) so that the two expressions become identical. We prefer a most general unifier (MGU) rather than adding unnecessary restrictions.

Unify(Knows(alice,y), Knows(x,mdp))
MGU = {x ↦ alice, y ↦ mdp}

It fails if constants clash, predicate names/arity differ, or a variable would have to contain itself (occurs check).

Part 5 · Stanford CS221

First-Order Modus Ponens

For a definite clause, first find one substitution that makes all antecedents match available facts. Then apply the same substitution to the conclusion.

∀x,y,z [(Takes(x,y) ∧ Covers(y,z)) → Knows(x,z)]
Given facts
Takes(alice,cs221)
Covers(cs221,mdp)
Matching substitution θ = {x ↦ alice, y ↦ cs221, z ↦ mdp}
Derived fact Knows(alice,mdp)
Remember: directly matching P(x) with P(alice) without instantiation/unification is the failed “first attempt” discussed in the lecture.
Part 6 · Extension beyond the lecture

FOL Resolution and Refutation

Resolution acts on clauses after suitable transformations to clause form, using unification to find complementary literals. To establish a query by refutation, add its negation and derive the empty clause □.

P(x) ∨ R(x)
¬P(alice)
──────────────
R(alice)   [θ = {x ↦ alice}]

A resolution step requires a complementary pair such as P(x) and ¬P(alice) that can be unified. The remaining literals form the resolvent.

Refutation of Q(alice)
1. ¬P(x) ∨ Q(x) (rule)
2. P(alice) (fact)
3. ¬Q(alice) (negated goal)
4. From 1 and 2: Q(alice) [θ={x↦alice}]
5. From 3 and 4: □ (contradiction)
